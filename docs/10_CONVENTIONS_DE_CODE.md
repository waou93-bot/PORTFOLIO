# 08 - Conventions de code - Portfolio immersif Nicolas Jez

## Statut

Aucune convention de code n'est imposee avant identification de la stack.

## Principes de depart

- Noms explicites et modules de taille raisonnable.
- Validation reproductible documentee avec le projet.
- Changements minimaux et facilement revertibles.
- Aucun secret ou asset volumineux dans le code sans decision tracee.
