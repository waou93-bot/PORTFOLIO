# Stratégie — Positionnement

## Promesse (héro, 5 s)

> « Je conçois des expériences web qui ne ressemblent pas à des templates. »

## Sous-positionnement

> Direction artistique, UX/UI, landing pages immersives et développement front-end.

## Levier de preuve

Le portfolio EST la démonstration : identité propre, études de cas honnêtes, performance mesurée, accessibilité réelle, mobile soigné.

## Ce que nous ne disons PAS

- Pas de superlatifs vides (« uniques », « exceptionnels »).
- Pas de promesse de résultat commercial non vérifié.
- Pas de jargon d'agence (« synergie », « 360° », « pushing boundaries »).
- Pas de « passionné » sans preuve.

## Différenciation (positionnement français rare)

1. **Direction artistique + développement dans la même main** (peu de profils FR affichent les deux).
2. **Honnêteté des cas** : périmètre exact, crédits partagés, limites assumées.
3. **Performance et accessibilité publiées** comme preuve de craft.
4. **FR soigné** (marché sous-servi), EN prêt.
5. Cadre éditorial premium qui sert des univers très différents (metal, culture, territoire, produit) sans les écraser.

## Taxonomie des services

| Service                  | Détail                                                                      |
| ------------------------ | --------------------------------------------------------------------------- |
| Direction artistique web | Identité visuelle digitale, univers graphiques, art direction d'interfaces  |
| UX / UI design           | Architecture de l'information, parcours, maquettes desktop/mobile           |
| Landing pages immersives | Narration, motion, expériences qui marquent                                 |
| Développement front-end  | Intégration soignée, animations, performance                                |
| Motion design            | Animations d'interface, transitions, previews                               |
| Création assistée par IA | Génération d'images, exploration visuelle (mention discrète, sans promesse) |

## Audiences prioritaires (ordre)

1. **Structures / studios / agences** qui cherchent un prestataire ou un collaborateur créatif-développeur.
2. **Recruteurs** (studios créatifs, boîtes tech) pour un poste de creative developer / art director web.
3. **Clients directs** (marques, artistes, collectivités, commerces) avec un budget projet.
4. **Pairs / communauté créative** (référencement, recommandation, veille).
