# Stratégie — Audiences et parcours

## Personas d'évaluation (heuristiques — pas une étude utilisateur réelle)

### P1 — Studio créatif (ex: petite agence web parisienne)

- **Objectif** : trouver un freelance creative developer / art director pour un projet client.
- **Attend** : niveau de finition, capacité à porter la DA, propreté d'intégration, fiabilité.
- **Décision en** : ~30–60 s sur l'accueil, puis 1–2 études de cas.
- **Levier** : qualité visuelle immédiate, crédits clairs, contact direct.

### P2 — Recruteur (studio/boîte tech)

- **Objectif** : évaluer des compétences précises (motion, front, DA, responsive, accessibilité).
- **Attend** : preuves techniques, mentions d'outils, profondeur des cas.
- **Levier** : pages projets détaillées, mentions stack, accessibilité/perf affichées.

### P3 — Client direct (marque, artiste, collectivité)

- **Objectif** : faire réaliser un site ou une landing.
- **Attend** : exemples parlants, compréhension de son univers, ton rassurant.
- **Levier** : études de cas lisibles sans jargon, parcours de contact court, formulaire simple.

### P4 — Communauté créative / pair

- **Objectif** : référencement, recommandation.
- **Levier** : exécution remarquable, transparence, originalité.

## Contraintes d'attention (30 s)

- Hero : identité + promesse + CTA en < 5 s.
- Section Selected Works : visible sans scroll ou presque, cartes lisibles avec rôle/année/secteur/statut.
- Le parcours d'un prospect pressé : héro → 1 carte projet → CTA contact. Ne rien cacher entre ces étapes.
